## 📖 About (אודות)
*(Hebrew below)*

**Tech Toolkit** is a massive, meticulously curated library of over **5,200+ authentic terminal commands**, PowerShell scripts, WMI classes, and Sysinternals utilities. Designed specifically for IT technicians, it features a zero-latency live search engine and a built-in AI script generator powered by Google's Gemini Flash.

**מאגר פקודות טרמינל Tech Toolkit** הוא כלי מקצועי לטכנאים הכולל למעלה מ-**5,200+ פקודות מסוף מקוריות**, סקריפטים של PowerShell, מחלקות WMI וכלים של Sysinternals. המאגר עוצב במיוחד עבור טכנאי IT וכולל מנוע חיפוש חי ללא השהיה, ומחולל סקריפטים מבוסס בינה מלאכותית (Google Gemini).

## ✨ Features (מאפיינים מרכזיים)

### ⚡ Zero-Latency Live Search
Search through thousands of commands instantly. The UI updates in real-time as you type, filtering by command name, description, or category.

### 🤖 Built-in AI Script Generator & Explainer
Need a custom script or an explanation for a command? Ask the built-in AI assistant in plain English or Hebrew. It will instantly explain, format, and prepare the script for download (.bat, .ps1, .sh).

### 🌍 Dual Language Support (עברית / English)
Fully translated interface and smart descriptions. Toggle between English and Hebrew seamlessly. The layout automatically adjusts to RTL for perfect Hebrew typography.

### 💾 1-Click Download & Copy
Don't waste time typing. Every command comes with dedicated `Copy` and `Download` buttons. The system intelligently detects the OS and command type to generate the correct file extension (`.bat`, `.ps1`, `.sh`).
