## 🌟 About (אודות)
*(Hebrew below)*

**Tech Toolkit** is a massive, meticulously curated library of over **5,200+ authentic terminal commands**, PowerShell scripts, WMI classes, and Sysinternals utilities. Designed specifically for IT technicians, it features a zero-latency live search engine and a built-in AI script generator powered by Google's Gemini Flash.

**ארגז הכלים לטכנאי** הוא מאגר מסיבי ומדויק של מעל **5,200+ פקודות טרמינל אותנטיות**, סקריפטים של PowerShell, מחלקות WMI וכלי Sysinternals. המערכת תוכננה במיוחד עבור אנשי IT וטכנאים, והיא כוללת מנוע חיפוש חי ללא השהיות ומחולל סקריפטים חכם מבוסס בינה מלאכותית (Google Gemini).

## ✨ Features (תכונות מרכזיות)

### 🔍 Zero-Latency Live Search
Search through thousands of commands instantly. The UI updates in real-time as you type, filtering by command name, description, or category.

### 🤖 Built-in AI Script Generator
Need a custom script? Ask the built-in AI assistant in plain English or Hebrew. It will instantly write, format, and prepare the script for download (.bat, .ps1, .sh).
*Features auto-fallback architecture to guarantee high availability even during API spikes.*

### 🌍 Dual Language Support (עברית / English)
Fully translated interface and descriptions. Toggle between English and Hebrew seamlessly. The layout automatically adjusts to RTL for perfect Hebrew typography.

### 💾 1-Click Download & Copy
Don't waste time typing. Every command comes with dedicated `Copy` and `Download` buttons. The system intelligently detects the OS and command type to generate the correct file extension (`.bat`, `.ps1`, `.sh`).

## 🚀 Installation & Usage (התקנה ושימוש)

This tool is **100% Offline-First** (excluding the AI generator). No Node.js, no servers, no databases required to run the core library!

1. Clone the repository:
   ```bash
   git clone https://github.com/dor2500/Command-Library-CMD-Terminal-.git
   ```
2. Navigate to the folder:
   ```bash
   cd Command-Library-CMD-Terminal-
   ```
3. Open `index.html` in any modern web browser.
4. **Done.** 

*For AI capabilities, ensure you have an active internet connection.*
